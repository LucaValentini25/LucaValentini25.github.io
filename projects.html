Brain App

AIPythonPersonal

Solo Developer · Personal project

Local-first AI assistant with a test suite of 323 cases that runs green in 77 seconds and 17 documented architecture decisions. Layered architecture with a pure domain layer that has zero upward dependencies and zero SQL outside repositories. Core principle: the LLM never decides an action — it classifies intent and extracts structured data with constrained decoding, while deterministic code executes every action, so the product keeps working when the model is unavailable. Runs end to end with no cloud; cloud models are optional and swappable at runtime across four interchangeable backends. The code stays private.

Python · FastAPI · SQLite · Vue 3 · Local LLMs (Ollama)
Private repo — architecture available on request
