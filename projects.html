snackdown.unity

Snackdown

Solo developer · built with Claude Code · Multiplayer · Netcode · Open source

A 2D last-player-standing platformer, rebuilt from scratch so the server is the authority.

  • Client-side prediction and server reconciliation written by hand: Netcode for GameObjects doesn't include them.
  • Snapshot interpolation for remote players on a fixed 30 Hz tick.
  • Join by Unity Relay code or LAN IP, with connection approval.
  • Netcode for GameObjects
  • Relay / Lobby
  • Unity 6
  • EditMode tests

brain-app/

Brain App

Solo developer · personal project · Python · AI · Architecture

A local-first AI assistant where the LLM never decides an action: it understands what you ask, and deterministic code does the work.

  • Runs end to end with no cloud; cloud models are optional.
  • Switch between 4 model backends live, without restarting.
  • RAG memory inside the same SQLite database, and it keeps working if the model is down.
  • Python
  • FastAPI
  • SQLite
  • Vue 3
